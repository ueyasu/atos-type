# アトス バトルタイピング

日本の小学生向けのローマ字タイピング練習ゲームです。ローマ字の習熟とタイピングの正確性を目標とし、サイドビューのファンタジー RPG 風のバトル形式で楽しく練習できます。

公開 URL: <https://ueyasu.github.io/atos-type/>

## ゲームの流れ

1. **タイトル** — スペースキー / クリックでメニューへ
2. **メニュー** — 「ゲームスタート」または「せってい」を選択
3. **難易度選択** — かんたん / ふつう / むずかしい から選択。むずかしいをクリアすると「インフィニティ」が解放
4. **バトル** — スライム → ゴブリン → スケルトン → ゴーレム → ドラゴンの 5 体をローマ字入力で撃破
5. **スコア表示** — タイプ文字数・正確性・クリア時間・ベストタイムを表示

> **インフィニティ**: むずかしいと同じ構成で、ドラゴンを倒してもスライムに戻ってループし続ける（クリアはなく、HP が尽きるまで戦う）。ループするごとに敵の攻撃間隔とダメージが 1.3 倍になり、ベストスコア（タイプした文字数）を記録する。

- 1 キー正タイプごとに主人公が攻撃します。
- ミスタイプや時間切れで敵が反撃し、主人公の HP が減少します（0 になるとゲームオーバー）。

## 主な機能

- **ローマ字ガイド**: 入力すべきローマ字をひらがなと併記表示。入力済み文字は色を変えて表示
- **手のピクトグラム**: 次に打つキーを使う指の指先に赤丸を表示（標準タッチタイピング準拠）
- **表記ゆれ設定**: じゃ→`ja`/`zya`、し→`shi`/`si`、つ→`tsu`/`tu` など、学校で習う表記に合わせてガイドを切り替え可能（どちらの入力も常に正解）
- **ローマ字表示の大文字/小文字切り替え**
- **効果音**: 攻撃・被弾・敵交代・クリア・ゲームオーバーの各 SE
- **ベストタイム記録**: 難易度ごとに localStorage へ保存（インフィニティはベストスコア＝タイプ文字数を記録）

## 開発環境

必要: Node.js 20 以上

```bash
npm install      # 依存パッケージのインストール
npm run dev      # 開発サーバ起動（http://localhost:5173）
npm run build    # 型チェック + 本番ビルド（dist/）
npm run preview  # 本番ビルドのプレビュー
npm test         # タイピングエンジンの単体テスト
```

## 技術スタック

| 役割 | 技術 |
|---|---|
| UI / 全体管理 | React 19 + TypeScript + Vite |
| バトル描画 | PixiJS v8（WebGL） |
| アニメーション | GSAP |
| スタイリング | Tailwind CSS v4 |
| 状態管理 | Zustand v5（localStorage 同期） |
| テスト | Node.js 標準機能による TS 直接実行 |

## デプロイ

GitHub Actions（`.github/workflows/deploy.yml`）が main ブランチへの push を検知し、ビルドして GitHub Pages へ自動デプロイします。

## ディレクトリ構成

```
src/
├── assets/
│   ├── images/          # 主人公 hero.png（透過PNG）＋敵・背景・斬撃（SVG）
│   └── se/              # 効果音（mp3）
├── components/          # 汎用・バトル画面用 UI
├── data/                # 単語・敵のマスターデータ
├── hooks/               # タイピング・バトル進行ロジック
├── lib/                 # ローマ字タイピング判定エンジン
├── pixi/                # バトル描画（PixiJS + GSAP）
├── scenes/              # 各画面
├── store/               # Zustand ストア
└── utils/               # 効果音再生・指割り当て
```

詳細は [docs/implementation.md](docs/implementation.md) を参照してください。
